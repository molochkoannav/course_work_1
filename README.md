# Курсовой проект: Анализ финансовых транзакций с веб-интерфейсом

## О проекте

Этот проект был разработан в рамках курсовой работы. 
Я занималась разработкой серверной части приложения для анализа банковских транзакций. 
Серверная часть получает данные о тратах, валютах, акциях и формирует JSON-ответы для отображения на веб-страницах.

**Суть проекта:** 
пользователь вводит дату и время, а сервер анализирует все транзакции с начала месяца по указанную дату, 
добавляет курсы валют и стоимость акций, рассчитывает кешбэк и возвращает структурированный JSON.

## Основные функции

### 1. Главная страница (`views.py`)

Модуль `views.py` отвечает за генерацию JSON-ответов. Здесь реализована главная функция, которая:

- Принимает строку с датой и временем в формате `YYYY-MM-DD HH:MM:SS`
- Определяет период анализа: с **первого числа месяца** входящей даты по **входящую дату**
  - Пример: `20.05.2020` → данные с `01.05.2020` по `20.05.2020`
- Формирует JSON со следующими полями:

#### Приветствие
В зависимости от времени суток:
- `"Доброе утро"` (04:00–11:59)
- `"Добрый день"` (12:00–16:59)
- `"Добрый вечер"` (17:00–23:59)
- `"Доброй ночи"` (00:00–03:59)

#### Данные по каждой карте
- последние 4 цифры карты
- общая сумма расходов
- кешбэк (1 рубль на каждые 100 рублей)

#### Дополнительно
- Топ-5 транзакций по сумме платежа
- Курсы валют (из внешнего API)
- Стоимость акций из S&P500 (из внешнего API)

### Пользовательские настройки (`user_settings.json`)

Валюты и акции для отображения задаются в этом файле. Пример содержимого:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

### 2. Сервисы (services.py)

Модуль содержит вспомогательные сервисы

#### 2.1 Простой поиск

Назначение: пользователь передаёт строку для поиска, функция возвращает JSON
со всеми транзакциями, содержащими запрос в описании или категории.

#### 2.2 Поиск по телефонным номерам

Назначение: возвращает JSON со всеми транзакциями, 
содержащими в описании мобильные номера.

#### 2.3 Поиск переводов физическим лицам
Назначение: возвращает JSON со всеми транзакциями, которые относятся к переводам физическим лицам.

Критерии отбора:
- Категория транзакции — Переводы
- В описании есть имя и первая буква фамилии с точкой

### 3. Отчёты (reports.py)

Реализованы функции для формирования аналитических отчётов:

- Декоратор
Записывает результат функции-отчёта в файл с именем по умолчанию или с указанным именем.
(например, report_20241215_143022.json)
- Функция `get_report`
Принимает на вход: датафрейм с транзакциями, название категории, опциональную дату (если не передана — берётся текущая)
Возвращает: траты по заданной категории за последние 3 месяца (от переданной даты)
